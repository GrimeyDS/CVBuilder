# Recommended tools and programs

This is a list of recommended tools and programs you should install to work on this project.

##Visual Studio
https://visualstudio.microsoft.com/

##SQL Server Management Studio
https://learn.microsoft.com/en-us/sql/ssms/download-sql-server-management-studio-ssms?view=sql-server-ver16

##Azure Data Studio (optional)
https://azure.microsoft.com/en-us/products/data-studio
A more lightweight alternative to SQL Server Management Studio. If you install SSMS, it will ask you to install ADS alongside it. I personally like it more because it's based on VSCode and quicker to work with.

##SQL Server Developer Edition
https://go.microsoft.com/fwlink/p/?linkid=2215158&clcid=0x409&culture=en-us&country=us
This will allow you to create and run a database locally. **DO NOT USE THE EXPRESS VERSION!**

##Fork
https://git-fork.com/
An excellent git client with a friendly UI. You will also need to install git itself.

##Bruno
https://www.usebruno.com/
A free, open-source and fully offline alternative to Postman to easily test your API endpoints.
